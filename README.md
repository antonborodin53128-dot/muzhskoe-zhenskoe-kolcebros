# Кольцеброс — конкурс «Мужское / Женское»

Участнику даётся 10 колец, по 2 на каждый из 5 цветов. Нужно набросить кольцо нужного цвета на нужную палку.
Ведущий сам считает попадания и нажимает на пульте, сколько баллов добавить: **10, 15, 20, 25 или 30**.

## Страницы

- `/` — пульт ведущего (для телефона): количество участников, баллы, «Отменить последнее», «Следующий участник», имена, сброс игры.
- `/screen` — экран для гостей (проектор): имя, крупный счёт, рейтинг справа, итоги в конце.

## Запуск

```
pip install -r requirements.txt
python app.py              # http://localhost:10000
gunicorn app:app           # на хостинге; настройки лежат в gunicorn.conf.py
```

Состояние игры сохраняется в файл (путь можно задать переменной `KOLCEBROS_STATE_FILE`) и переживает перезапуск сервера.

## В общем сборнике

`kolcebros_app.py` не зависит от `app.py`: в сборнике его подключают как `from kolcebros_app import app` и монтируют
в `DispatcherMiddleware`, например в `/women/kolcebros`. Все ссылки в нём относительные.
